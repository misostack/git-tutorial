# Open Knowledge Format (OKF)

OKF represents knowledge as a directory of markdown files with YAML frontmatter. The skill was installed with `npx skills add fabricioctelles/skills -s okf-open-knowledge-format` (recorded in `skills-lock.json`).[^okf-md] This bundle follows OKF v0.2.
