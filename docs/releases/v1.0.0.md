# Git Tutorial v1.0.0: Secure Access & User Management

_Released on: 2026-10-08_

The first stable release adds authentication and admin user management to the API. It also documents the Git workflow the project follows.

## 🎉 What’s New

- **Secure application access (#123):** The API now requires authentication, so only authorized users can reach protected endpoints.
- **Admin user management (#124):** Admin users can now manage user accounts through the API.
- **Git flow documentation:** A new guide describes the branching model, commit convention and rebase workflow used in this project.

## ✨ Improvements

- **Sensitive data handling:** Sensitive user fields are excluded from API responses through serialization.
- **Configuration:** Sensitive values now come from environment config, and a `.env.sample` is included to help with setup.
- **Project docs:** Added a sample user list and a description of the module, and started keeping a changelog and release notes.

## 🐛 Bug Fixes

- Fixed an issue where sensitive user data could be exposed in API responses.
- Resolved a problem where sensitive user data was stored directly in code instead of environment config.
