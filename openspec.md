# Openspec Blueprint

OpenSpec is a lightweight and configurable framework for creating and managing software specification.

## Installation

```sh
npm install -g @fission-ai/openspec@latest
```

## Setup

```sh
openspec init
```

## Commands

/opsx:explore - map the problem and understand the codebase
/opsx:propose - draft proposal.md, specs/, design.md, tasks.md
/opsx:apply - implement tasks from the specification
/opsx:verify - check the implementation matches the spec
/opsx:archive - archive completed changes

## Q&A

> What is openspec?

- Spec-driven development (SDD) for AI coding assistants.

> Why should you use openspec?

- Requirements come from many resources, it is a painful experience to manage changes: new request, removed feature,...

> Who can use openspec?

- Especially PM and BA

> When should you use openspec?

- Mostly beginning of project, and beginning of the sprint

> Where should you use openspec?

- Directly in your code base with an AI Agent. Eg: Claude
